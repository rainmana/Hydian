# Hydian

**One endpoint. Every MCP server.**

Hydian is a small, local-first Model Context Protocol multiplexer. It gives MCP
clients one stable endpoint while connecting to the stdio and Streamable HTTP
servers an operator already uses.

## Start here

1. Read the [configuration guide](configuration.md).
2. [Import](importing.md) an existing client configuration.
3. Review the [security model](security-model.md).
4. Use [troubleshooting](troubleshooting.md) when `hydian doctor` reports an
   issue.

The name takes inspiration from the Hydian Way in *Star Wars*: a well-known
route joining distant systems. Hydian similarly connects separate MCP servers
through a single route. This unofficial open-source project is not affiliated
with or endorsed by Lucasfilm or Disney.
